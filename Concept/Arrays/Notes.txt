1. Adding and removing elements

1. push() — Add to the end
let arr = [10, 20, 30];
arr.push(40);
console.log(arr);
// [10, 20, 30, 40]


Modifies the original array and returns the new length.


2. pop() — Remove from the end
let arr = [10, 20, 30];
let removed = arr.pop();

console.log(arr);     // [10, 20]
console.log(removed); // 30


Returns the removed element.


3. shift() — Remove from the beginning
let arr = [10, 20, 30];
arr.shift();
console.log(arr);
// [20, 30]




4. unshift() — Add to the beginning
let arr = [10, 20, 30];
arr.unshift(5);
console.log(arr);
// [5, 10, 20, 30]


Returns the new length of the array.



2. splice() vs slice()
These two methods look similar but behave differently.
5. splice() — Add, remove, or replace
let nums = [10, 20, 30, 40];

nums.splice(1, 2);

console.log(nums);
// [10, 40]


splice(1, 2) means start at index 1 and remove 2 elements (20 and 30).

You can also insert elements:
let nums = [10, 20, 30];

nums.splice(1, 0, 15);

console.log(nums);
// [10, 15, 20, 30]



6. slice() — Copy part of an array
let nums = [10, 20, 30, 40];

let result = nums.slice(1, 3);

console.log(result); // [20, 30]
console.log(nums);   // [10, 20, 30, 40]


slice(1, 3) starts at index 1 and stops before index 3.

Key difference: splice() modifies the original array; slice() does not.

3. reverse() and sort()

7. reverse() — Reverse the order
let nums = [1, 2, 3, 4];

nums.reverse();

console.log(nums);
// [4, 3, 2, 1]


This changes the original array.

8. sort() — Sort elements
By default, JavaScript sorts elements as strings, not necessarily as numbers.
let nums = [10, 5, 40, 2];

nums.sort((a, b) => a - b);

console.log(nums);
// [2, 5, 10, 40]


- (a, b) => a - b sorts in ascending order.
- (a, b) => b - a sorts in descending order.
let nums = [10, 5, 40, 2];

nums.sort((a, b) => b - a);

console.log(nums);
// [40, 10, 5, 2]



4. Methods that process array elements

Let's use this array for the next examples:
let nums = [1, 2, 3, 4, 5];


9. map() — Transform every element
let nums = [1, 2, 3, 4, 5];

let result = nums.map(n => n * 2);

console.log(result);
// [2, 4, 6, 8, 10]


Each number is multiplied by 2. map() returns a new array.


10. filter() — Keep matching elements
let nums = [1, 2, 3, 4, 5, 6];

let result = nums.filter(n => n > 3);

console.log(result);
// [4, 5, 6]


Returns a new array containing only elements that pass the condition.


11. reduce() — Combine elements into one result
let nums = [1, 2, 3, 4, 5];

let total = nums.reduce((sum, n) => {
  return sum + n;
}, 0);

console.log(total); // 15


How it works:
- Start with sum = 0.
- Add 1 → 1.
- Add 2 → 3.
- Add 3 → 6.
- Continue until the total is 15.
reduce() is commonly used for totals, averages, and grouping data. You listed it twice; it's the same method.


12. forEach() — Perform an action for each element
let nums = [1, 2, 3];

nums.forEach(n => {
  console.log(n);
});

// 1
// 2
// 3


Useful when you want to print values or perform an action for each item. It returns undefined, not a new array.


5. Searching and checking elements

13. find() — Get the first matching element
let nums = [10, 20, 30, 40];

let result = nums.find(n => n > 25);

console.log(result); // 30


Returns the first matching element, or undefined if no match exists.


14. some() — Does at least one element match?
let nums = [1, 3, 5, 8];

let result = nums.some(n => n % 2 === 0);

console.log(result); // true


Returns true because 8 is even. If no element matches, it returns false.


15. every() — Do all elements match?
let nums = [2, 4, 6, 8];

let result = nums.every(n => n % 2 === 0);

console.log(result); // true


Returns true only if every element passes the condition.


6. Quick comparison
Method	Returns	Original array changed?
push() / unshift()	New length	Yes
pop() / shift()	Removed element	Yes
splice()	Removed elements	Yes
slice()	New array	No
reverse()	Reversed array	Yes
sort()	Sorted array	Yes
map()	New array	No
filter()	New array	No
reduce()	Accumulated result	Not inherently
forEach()	undefined	Not inherently
find()	First matching element	No
some()	Boolean	No
every()	Boolean	No
